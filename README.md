# 스마트폰 메신저 — 확장 v3.5.50

SillyTavern의 Smartphone Messenger v3.5 프롬프트·테마 세트와 함께 사용하는 보조 확장입니다. 메신저/서사 전환, 속마음 표시, 음주 상황 감지, 통화 응답 선택지와 로딩 메시지를 제공합니다.


## 설치

1. 함께 배포된 프롬프트와 테마를 가져옵니다. 폰 화면은 기존 JS Runner를 사용하며, 속마음 표시는 세트의 Regex 설정을 사용합니다.
2. SillyTavern의 확장 설치 메뉴에 **이 저장소의 GitHub URL**을 입력합니다.
3. 페이지를 새로고침하고, **마법봉 → 스마트폰 메신저**에서 확장을 켭니다.


## 자발적 음주와 음주 모드

- **음주 모드 ON**: 캐릭터가 이미 음주 중인 상태로 시작합니다.
- **캐릭터의 자발적 음주 허용**: 음주 모드가 OFF여도 캐릭터가 스스로 술을 시작할 수 있습니다. 확장 자체가 ON이어야 지침이 전달됩니다.
- 관계의 갈등·상처·거절감·서운함, 고통스러운 사건·상실·실패·외로움·누적 스트레스·피로를 계기로 고려합니다. 평소 술을 좋아하는 성격, 저녁의 한잔, 식사·퇴근 후 휴식, 모임·축하·기분 전환도 계기가 될 수 있습니다. 큰 사건이나 유저의 명시적인 권유가 필수는 아닙니다.
- 실제 선택은 캐릭터의 성격·평소 습관·현재 상황을 보고 모델이 합니다. 모든 갈등마다 자동으로 술을 마시거나 강제로 취하게 만들지는 않습니다.
- 실제 음주가 답변에 나타나고 확장이 감지하면 음주 프롬프트와 채팅 상태를 켜고 알립니다. 마시고 싶다는 생각, 질문·계획, 과거 음주, 괴로운 감정만으로는 시작 처리하지 않습니다.
- 허용을 OFF로 하면 자발적 시작 지침을 제한합니다. 이미 시작한 음주를 즉시 없애는 설정은 아닙니다.
- 자연어 감지이므로 모든 표현을 알아내지는 못하며, 모델마다 자발적 음주 빈도와 표현이 달라질 수 있습니다.


## 선택지

- **선택지 출력**을 켜면 통화/서사 답변 아래에 1~3번 AI 선택지와 **4번 직접 입력**을 표시합니다.
- 직접 입력은 기존 입력창으로 이동하며 작성하던 초안을 보존합니다. 제목 옆의 **선택지 다시 생성**으로 다시 요청할 수 있습니다.
- AI 생성 요청에 현재 선택된 유저 페르소나와 이름, 최근 대화를 전달합니다. 유저의 성격·말투·관계·경계에 맞는 선택지를 요청하며, 페르소나가 바뀌면 이전 선택지를 다시 생성합니다.
- 생성 대기/실패 시에는 기본 선택지가 표시될 수 있습니다. 기본 선택지는 개별 페르소나에 맞춰 생성된 결과가 아닙니다.
- 영어/일본어 선택지는 괄호 안에 한국어 번역을 함께 표시하고, 선택하면 대화 언어의 문장만 전달합니다.
